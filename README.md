# Add 算子测试脚本 - 使用说明

## 概述

本脚本用于自动化测试 CV Add 算子，支持：
- 遍历不同尺寸组合（Rows × Cols 笛卡尔积）
- 每 10 个组合提取一次新增日志（分文件存储）
- 算子执行完毕后，从容器内打包 `/home/paas/ascend/` 目录到宿主机

---

## 脚本文件

| 文件 | 说明 |
|------|------|
| `test_add_operator.sh` | 正式版本（在宿主机运行） |
| `test_add_mock.sh` | 模拟版本（本地验证用） |

---

## 快速开始

### 命令格式

```bash
./test_add_operator.sh <目标IP> <日志ID> [步长] [最大组合数] [容器ID]
```

### 参数说明

| 参数 | 位置 | 默认值 | 说明 |
|------|------|--------|------|
| 目标IP | 1 | **必填** | 测试服务 IP 地址 |
| 日志ID | 2 | **必填** | 容器日志目录 ID（如 `0`） |
| 步长 | 3 | `5` | Rows 和 Cols 的递增步长 |
| 最大组合数 | 4 | `0`（全部） | `>0` 时限制执行数量，用于快速验证 |
| 容器ID | 5 | 无 | 容器 ID 或名称，用于打包 ascend 目录 |

### 运行示例

```bash
# 1. 默认配置（步长5，跑全部 37120 个组合）
./test_add_operator.sh 172.18.0.4 0

# 2. 步长10（减少组合数到 9344）
./test_add_operator.sh 172.18.0.4 0 10

# 3. 快速验证（只跑前 100 个组合）
./test_add_operator.sh 172.18.0.4 0 5 100

# 4. 完整参数：步长10 + 限制1000个 + 指定容器
./test_add_operator.sh 172.18.0.4 0 10 1000 2fe5937ad00a

# 5. 使用容器名称
./test_add_operator.sh 172.18.0.4 0 5 0 test-ssh-2
```

## 尺寸组合说明

### 范围

| 维度 | 范围 | 说明 |
|------|------|------|
| Rows | 1 ~ 721 | 图像行数 |
| Cols | 1 ~ 1280 | 图像列数 |

### 组合方式（笛卡尔积）

```
(1,1), (1,6), (1,11), ..., (1,1276),
(6,1), (6,6), (6,11), ..., (6,1276),
...
(721,1), (721,6), ..., (721,1276)
```

### 步长与组合数关系

| 步长 | Rows 数量 | Cols 数量 | 总组合数 | 预估耗时 |
|------|-----------|-----------|----------|----------|
| 5 | 145 | 256 | 37,120 | ~12 小时 |
| 10 | 73 | 128 | 9,344 | ~3 小时 |
| 20 | 37 | 64 | 2,368 | ~45 分钟 |
| 50 | 15 | 26 | 390 | ~8 分钟 |

> 预估耗时基于每次请求约 1 秒计算，实际取决于网络延迟

## 执行流程

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 初始化                                                    │
│    - 检查参数                                                 │
│    - 创建日志输出目录 ./test_results/                         │
│    - 记录日志文件初始位置                                      │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 2. 遍历尺寸组合（笛卡尔积）                                   │
│    - 外层: Rows = 1, 1+步长, 1+2×步长, ..., 721              │
│    - 内层: Cols = 1, 1+步长, 1+2×步长, ..., 1280             │
│    - 每个组合发送 curl POST 请求                              │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 3. 每 10 个组合 → 提取新增日志                                │
│    - 增量读取（不重复）                                       │
│    - 写入独立文件: batch_001.log, batch_002.log, ...          │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 4. 算子执行完毕 → 容器打包                                    │
│    - 容器内: tar -czf /tmp/xxx.tar.gz /home/paas/ascend      │
│    - 复制到宿主机: docker cp → ./logs_archive/                │
│    - 清理容器临时文件                                         │
└─────────────────────────────────────────────────────────────┘
```

## API 请求格式

脚本发送的 curl 请求：

```bash
curl -X POST http://{目标IP}:2580/testing/task/create \
  -H "Content-Type: application/json" \
  -d '{
    "testingJobList": [{
        "testingFuncName": "TestAddPerformance",
        "testingExtParam": {
            "imageRows": "1",
            "imageCols": "1",
            "XMatType": "8UC3",
            "frameCount": "1",
            "isPerformance": "false"
        }
    }],
    "testingTaskDescription": "cv add operator",
    "testingType": "SINGLE"
}'
```

## 注意事项

1. **运行环境**：脚本需在能访问目标 IP 和 Docker 的宿主机上运行
2. **Docker 权限**：打包容器目录需要 Docker 执行权限
3. **日志分文件**：每 10 个组合一个文件，避免单文件过大
4. **增量读取**：日志采用增量读取，不会重复提取
5. **超时设置**：curl 连接超时 10 秒，最大等待 30 秒

## 常见问题

### Q: 如何只测试部分组合？
```bash
# 只跑前 100 个组合
./test_add_operator.sh 172.18.0.4 0 5 100
```

### Q: 如何调整步长？
```bash
# 步长设为 20，组合数大幅减少
./test_add_operator.sh 172.18.0.4 0 20
```

### Q: 不想打包容器目录？
```bash
# 不传容器ID参数即可跳过打包
./test_add_operator.sh 172.18.0.4 0
```

### Q: 如何查看容器列表？
```bash
docker ps | grep ccom
```
